# CLAUDE.md

## Project

Public website for Uppsala Blåsarsymfoniker (wind orchestra): a static site
generated by Gleam from Markdown content, edited by the board through Sveltia
CMS and by agents directly in `content/`. See `docs/plan.md` for requirements
and decisions, and `docs/ubs-profile.html` for the graphical profile.

## Gleam CLI

Always manage the project and its dependencies with the `gleam` CLI. Never
edit `gleam.toml` or `manifest.toml` by hand to do something a command does.

| Task | Command |
|---|---|
| Add a dependency | `gleam add <package>` (`--dev` for test-only) |
| Remove a dependency | `gleam remove <package>` |
| Update dependencies | `gleam update` |
| Fetch dependencies | `gleam deps download` |
| Build | `gleam build` |
| Test | `gleam test` |
| Format | `gleam format` |
| Generate the site | `gleam run` |

## Git

- Use [Conventional Commits](https://www.conventionalcommits.org/)
  (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`, `ci:`).
- Work directly on `main`. Don't create feature branches or pull requests
  unless asked.
- Make small commits as you go: one logical change each, committed as soon
  as it builds and its tests pass, rather than one large commit at the end.

## Code style

- **Swedish first, English throughout.** User-facing text exists in both
  languages; code, comments, and commit messages are English.
- **Result types for errors.** Content problems are returned as errors
  naming the file, never panics; `let assert` only in tests.
