# Redigera webbplatsen

Du har bjudits in som redaktör för Uppsala Blåsarsymfonikers webbplats.

1. Öppna mejlet från GitHub och klicka på länken. Skapa ett GitHub-konto, eller
   logga in om du redan har ett, och acceptera inbjudan. Den gäller i 7 dagar.
2. Gå till <https://website.uppsalablasarsymfoniker.workers.dev/admin/> och
   välj **Sign in with GitHub**. Godkänn appen **UBS Website CMS** första gången.
3. Redigera och spara. Ändringen syns på webbplatsen efter någon minut.

Nya konserter och nyheter skrivs på svenska. Vill du lägga till en engelsk
översättning slår du på engelska i redigerarens meny.

Problem? Kontakta den som bjöd in dig.
