04

Type Scale

Seven steps, hand-tuned rather than modular. Every size on this page comes from this scale — if a design needs a size that isn't here, extend the scale rather than adding a one-off. Display is for the website's home page title only, on screens 768px and wider; narrower screens use H1.

05

Spacing & Radius

Spacing is a 4px base scale, which is Tailwind's default spacing unit, so --space-4 equals the utility p-4. Use these steps for component spacing; larger Tailwind steps (20, 24, 32…) are for page layout. Avoid fractional steps and arbitrary pixel values.

Corner radius

Each step is one DaisyUI radius token, and DaisyUI decides which components use it: 4px --radius-field buttons, inputs, selects, tabs · 6px --radius-selector badges, checkboxes, toggles · 10px --radius-box cards, panels, modals, alerts.

Logo

Variants

The full-color logo is a single UBS Red fill, which is only 2.69:1 on UBS Black — below even the 3:1 floor for graphics. Use it on light surfaces only; every dark or saturated background takes a knockout.

Clear space

Keep a margin of at least 25% of the logo's height free on all four sides. At the 56px header size that is 14px; the hatched area shows the exclusion zone. Nothing — type, rules, image edges — may enter it.

Incorrect usage

✗ Never rotate
✗ Never stretch
✗ Never recolor off-brand
✗ Never add effects

Specifications

File formats SVG preferred for web & print; PNG only where SVG is unsupported
Approved variants Full color on light surfaces only. Elsewhere, one of the two supplied knockouts — solid white (ubs-logo-white.svg) or solid black (ubs-logo-black.svg) — on a background it clears 4.5:1 against

08

Status Colors

Status colors are functional, not brand identity — they exist to make an outcome legible at a glance. Each one clears WCAG AA both as a fill under light text and as text on the light surfaces; ratios below are computed live, and Surface is the governing case because it is the darkest light surface text sits on.

Error is deliberately not UBS Red. The brand red already owns primary actions and Dark Red owns their hover state, so reusing it left a failed save indistinguishable from a save button. Error is the same hue family but brighter and cleaner, which keeps it conventionally readable as an error while separating it from both brand reds. Warning is the AA-safe sibling of Warm Brass. Brass is 2.27:1 on light and can never carry text; Warning is the same hue taken dark enough to pass, so a caution reads as brass-family without failing contrast.

Color must never be the only signal. Pair every status with a word, an icon, or both — a red chip and a green chip are the same chip to a color-blind reader. DaisyUI's badge-* and alert-* components consume these tokens automatically.

09

Icons

Icons are single-color shapes that take the color of the text around them, so they follow every approved pairing without a rule of their own. Social platform icons come from Simple Icons (CC0) and are never shown in the platform's own colors — no Facebook blue, no Instagram gradient: next to UBS Red they would read as the louder brand.

Color The surrounding text color (currentColor as fill or stroke), including its hover color
Size 20px beside text; 24px when the icon stands alone, inside a tap area of at least 40px
Alone An icon without visible text carries an accessible name (aria-label) naming where it leads; beside text it is aria-hidden
Format Inline SVG, so it inherits color; never an icon font
