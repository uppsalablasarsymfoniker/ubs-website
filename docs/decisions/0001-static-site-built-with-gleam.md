# 0001. Static site built with Gleam

Status: Accepted · 2026-11-25

## Context

The site replaces a WordPress/Divi site. Board members and AI agents must both
be able to edit content, with as little technology as possible to host, patch,
or pay for.

## Decision

A static site generated by Gleam from Markdown files in this repository, built
in GitHub Actions. No server, no database, no request-time features.

Rejected: a hosted headless CMS (Sanity, Storyblok, Contentful) for its vendor
account and API dependency; a self-hosted CMS (Payload, Strapi, Directus) for
the server and database it needs; a Gleam server (Wisp/Mist), since nothing
needs a request-time feature.
