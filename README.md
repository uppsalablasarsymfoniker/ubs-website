# UBS website

The public website for Uppsala Blåsarsymfoniker, a wind orchestra: a static
site generated by Gleam (Lustre views, Tailwind v4) from Markdown and TOML in
`content/`. Preview: <https://uppsalablasarsymfoniker.github.io/ubs-website/>

## Run it

```sh
gleam test                            # run the tests
gleam run build                       # generate the site into dist/
python3 -m http.server 8000 -d dist   # preview at http://localhost:8000
```

`SITE_URL` sets the public address and base path; unset, the build targets
`http://localhost:8000`.

Every push to `main`, and a daily run, tests, builds and deploys the site to
GitHub Pages (`.github/workflows/deploy.yml`).

## Edit content

Content lives in `content/`: pages, concerts and news as `<slug>.sv.md` /
`<slug>.en.md` files, plus `members.toml` and `settings.toml`. Edit the files
directly, or use Sveltia CMS at `/admin` (configured in
`assets/admin/config.yml`), which commits to `main`.
